# tests — разбивка `src/index.html` на части

Это **полная рабочая копия** `src/index.html`, разложенная на отдельные файлы.
Оригинал `src/index.html` не изменялся и не изменяется — `tests/` всегда
пересобирается из него.

Открывается как обычная статическая страница (прямой путь к файлу, сборка не нужна):

```
tests/index.html
```

## Мобильная читалка (`≤880px`, режим чтения)

В разбиение добавлены два новых файла (свои в `src/index.html`):

* `css/09-mobile-reader.css` — вся мобильная читалка живёт в `@media (max-width:880px)`;
* `js/19-mobile-reader.js` — режим чтения, подключается последним.

Ключевое: если ширина ≤880px, `body` получает класс `reader` (`isReader()` в `01-core.js`).
В этом режиме:

* виден только текст главы: хром библиотеки, топбар, сайдбар, статусбар скрыты;
* тап-зоны по краям экрана (левая треть — назад, правая — вперёд, центр — показать/спрятать панель);
  краевые зоны скроллят текст и при открытой панели, прокрутка сама гасит панель;
* нижняя панель: ползунок прогресса главы, `%` и «осталось ≈ N мин», `Aa`, `‹/›`, оглавление;
* шит «Aa»: тема (день/ночь/сепия), размер шрифта, межстрочный интервал — применяются глобально;
* библиотека и оглавление на мобильном упрощены до списка (без обложек и инструментов).

Десктоп (`>880px`) не зависит от этих файлов — поведение прежнее.

## Что изменилось по сравнению с оригиналом

1. **Разметка и шапка** — побайтово те же, кроме замены `<style>…</style>` на
   9 `<link>` и `<script>…</script>` на 19 `<script src>`.
2. **CSS** — тот же текст, разнесённый по файлам; конкатенация файлов даёт
   исходный блок `<style>` байт-в-байт → каскад не изменился.
3. **JS** — тот же код, но без IIFE: ~226 верхнеуровневых имён теперь видны
   как `window.*`. На работу не влияет (проверено: коллизий с браузерными
   глобалами и с `id` элементов, которые вели бы к иной логике, нет —
   пересечение `synSec/synChips/synSrc/synRetry/toast` в оригинале уже
   перекрывало id-глобал внутри IIFE).
4. `"use strict"` продублирован в начале каждого JS-файла (строгий режим
   действует пофайлово).

## Как проверить, что копия не разошлась с оригиналом

```powershell
# 1. синтаксис каждого файла
Get-ChildItem tests\js\*.js | ForEach-Object { node --check $_.FullName }

# 2. оригинал не тронут
git status --short        # не должно быть изменений в src/
```

Побайтовая сверка (склейка обратно):

* `concat(tests/css/*.css)` === содержимое `<style>` из `src/index.html`;
* `concat(tests/js/*.js)` со снятыми строками `"use strict";` === тело
  `<script>` из `src/index.html` без строк `(function(){` и `})();`;
* `<head>` и разметка `<body>` в `tests/index.html` === оригиналу.

Смоук в headless Chrome (страницы дают одинаковый DOM и одну и ту же
заранее существующую ошибку `state.books` на строке 2183 — она есть и в
оригинале при чистом профиле):

```powershell
& "C:\Program Files\Google\Chrome\Application\chrome.exe" --headless=new `
  --virtual-time-budget=5000 --dump-dom "file:///D:/work/rov/tests/index.html"
```

## Важно

`tests/` — снимок. Правки вносить в `src/index.html`, затем пересобирать
`tests/` (или править синхронно в обе стороны). Ручные правки только
`tests/` расхождением с оригиналом не проверяются.
