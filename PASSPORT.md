# Паспорт проекта «Черновик»

## Тема проекта
Сайт-редактор для писателей «Черновик» (`rov.smartliba.ru`): пишешь книгу, ведёшь справочник мира и общаешься с ИИ — всё на одном сайте.

## Цель проекта
Сделать одно рабочее место для автора книги: структура глав, сам текст, справочник мира и помощник ИИ. Человеку не нужно прыгать между блокнотом, таблицей и чатом — всё в одном окне браузера.

## Задачи проекта
1. **Писать удобно** — редактор с главами: перетаскивание глав, автосохранение, история версий (снапшоты).
2. **Держать мир книги в порядке** — энциклопедия: сайт сам находит в тексте персонажей, места и события, показывает связи между ними и в каких главах встречаются.
3. **Помощь ИИ** — чат, который читает книгу и отвечает по её содержимому; ищет ошибки, исправляет и улучшает выделенный кусок текста, может создать книгу или главу по описанию.
4. **Писать с любого устройства** — на компьютере, планшете и телефоне; аккаунты, синхронизация между устройствами, резервные копии.

## Сегмент проекта (для кого)
Люди, которые пишут длинные тексты: романисты, фантасты, сценаристы, те, кто придумывает миры. Подойдёт и редактору. Всё работает в браузере — ставить ничего не надо.

## Методы, которые применялись в работе
| Метод | Что это давало |
|---|---|
| Наблюдение | Смотрел, как человек реально пишет и вычитывает, какие места мешают |
| Сравнение | Разбирал похожие программы (Scrivener, Word, Notion, чаты с ИИ) и брал лучшее |
| Пробные версии | Собрал 27 версий подряд, каждую проверял и правил |
| Тесты | Прогонял сценарии в браузере, смотрел скриншоты экранов |
| Проверка дизайна | После каждой правки просматривал вёрстку, цвета и телефонную версию |
| Анализ текста | Считал встречаемость имён, статистику слов и объём книги |

## Количество информационных источников
Около **13**: документация технологий (MDN, PHP, SQLite, nginx) — 4; обзоры и инструкции похожих редакторов — 7; справочники по типографике и удобству — 2.

## Технологии
HTML, CSS, JavaScript (без фреймворков и сборщика) · PHP на сервере (аккаунты, книги, сессии) · база SQLite/MySQL · данные в браузере (localStorage) плюс синхронизация на сервер · ИИ — DeepSeek через серверный релей.
