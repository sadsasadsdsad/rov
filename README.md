## ИИ-ассистент (js/22-assistant.js)

Чат по книге и правка выделенного текста. По умолчанию запросы идут через
сам сайт: браузер → `/api/ai.php` (PHP-релей) → прокси deepseek-web2api на
том же VPS (`127.0.0.1:8080`) → DeepSeek. Ключей у читателя нет — работает
с любого устройства, браузер не знает про прокси вообще.

### Установка на сервере (однократно)

1. `git pull && sudo bash setup-server.sh` — создаёт `/var/www/rov/.aikey`
   (ключ релея, в git не попадает) и `location = /api/ai.php` в nginx
   (rate-limit 20 р/мин, `fastcgi_read_timeout 300s`, без буферизации —
   нужен для SSE-стрима).
   Если nginx-конфиг сайта живой/ручной — разово:
   `sudo bash nginx-ai-patch.sh` (бэкап в /root/nginx-backup, `nginx -t`,
   перезагрузка; повторный запуск — no-op). Тот же скрипт выставляет
   `Cache-Control`: html — `no-cache` (иначе браузер кэширует index.html
   эвристически и после обновления показывает старую вёрстку — например,
   пилюлю ИИ из прошлой версии), статика — на сутки (`?v=` в index.html).
2. Ключ должен быть читаем PHP: `chown root:www-data /var/www/rov/.aikey &&
   chmod 640 /var/www/rov/.aikey` (оба скрипта ставят права сами).
3. Код прокси и его установка:
   ```
   scp web2api.tar.gz root@сервер:/root/
   ssh root@сервер 'cd /var/www/rov && sudo bash setup-ai.sh'
   ```
   Скрипт кладёт прокси в `/opt/web2api` (код + `.env` + `data/accounts.json`),
   собирает venv, пишет юнит `web2api.service` (слушает только 127.0.0.1,
   наружу не светит) и подставляет `.aikey` в `API_KEYS` прокси.
4. Проверка: `curl https://rov.smartliba.ru/api/ai.php?action=models` → 200.

### Режим со своим прокси (разработка)

Кнопка **ИИ** — в верхней панели (на месте «Все заметки»: заметки теперь
через Энциклопедию → вкладка «Заметки») → ⚙ → адрес `http://127.0.0.1:8080` и ключ
`sk-…` из панели прокси (`/webui/`) → «Сохранить». Браузер идёт напрямую в
локальный прокси (в `.env` прокси нужен `ALLOWED_ORIGINS=…`, в `server.py`
в CORSMiddleware — `allow_private_network=True`), ключ хранится только в
localStorage. Пустой адрес = режим по умолчанию, через сайт.

### Что умеет

- **Чат** — контекстом служит текущая книга, глава и живое выделение,
  ответ идёт потоком, у модели `deepseek-reasoner` отдельно показываются
  «Рассуждения».
- **Испр. / Улучш.** — две кнопки в панели выделения (рядом с Ж/К/Э+):
  первая чинит орфографию и пунктуацию, не переписывая текст;
  вторая улучшает стиль, сохраняя смысл (запрет канцелярита и штампов,
  объём ±10%). В модель уходит фрагмент с абзацами, «Применить»
  применяет ответ по месту: абзацы и заголовки сопоставляются с блоками
  выделения, теги `<h1>/<b>/<i>` и не тронутая часть соседнего абзаца
  остаются на месте (запасной путь — простая подмена, как раньше).
  Результат открывается в модалке — «Применить» подменяет фрагмент
  прямо в редакторе, «Копировать» — для режима только для чтения.
- **Создание книг и глав** — попросите словами (или чипом «＋ Новая книга»
  в панели): модель отвечает JSON-действием (`create_book` /
  `create_chapter` / `replace_chapter`), в ленте появляется карточка
  с планом (список глав, объём), книга/глава создаётся по кнопке —
  `<h1>` + `<p>`, служебные главы как в обычной книге, `persist()`.
  Служебные главы («Памятка», «Заметки») заменять нельзя.
- **Панель выделения** — менюшка и синонимы выезжают через ~0.85 с
  спокойного выделения, а не мгновенно (`transition-delay` в
  `04-editor.css` + `THESAURUS_DELAY`).
- **Кнопка ИИ** — пилюля в верхней панели редактора (на месте «Все заметки»)
  и в шапке библиотеки, с точкой связи (зелёная — онлайн, красная — сбой);
  заметки открыть через Энциклопедию → вкладка «Заметки». Кнопка
  **«Создать книгу»** — в шапке библиотеки (карточка «Новая книга» на
  телефоне скрыта читалкой).
- **Сбои** — если DeepSeek недоступен (5xx/429/обрыв сети), в ленте
  «DeepSeek временно недоступен — повторим через минуту» и кнопка
  «ПОВТОРИТЬ» (автоповтор один раз), в модалке правки — своя кнопка
  «ПОВТОРИТЬ». Статус связи в шапке панели тоже сам перепроверяется.
- Настройки (адрес, ключ, модель) — в шапке панели; пустой адрес = через
  сайт.

Файлы модуля: `src/js/22-assistant.js`, `src/css/12-assistant.css`,
разметка в `src/index.html`, релей `src/api/ai.php`, серверные скрипты
`setup-ai.sh` и `nginx-ai-patch.sh`. `dist/` держим в зеркале с `src/`.
