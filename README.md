# rov
rov.smartliba.ru

## ИИ-ассистент (js/22-assistant.js)

Чат по книге и правка выделенного текста через локальный прокси
deepseek-web2api (бесплатный DeepSeek, OpenAI-совместимый `/v1/chat/completions`).
Прокси живёт на вашем компьютере, сайт обращается к нему прямо из браузера —
сервер ничего не знает про ключи.

### Как включить

1. Запустите прокси на своём компьютере (`start.bat`) — проверка:
   `http://127.0.0.1:8080/health` должен вернуть `{"status":"ok"}`.
2. В `.env` прокси пропишите CORS, иначе браузер с `rov.smartliba.ru`
   не пропустит кросс-доменный запрос:

   ```
   ALLOWED_ORIGINS=https://rov.smartliba.ru,http://127.0.0.1:8088
   ALLOW_CORS_CREDENTIALS=false
   ```

   и в `server.py` внутри `CORSMiddleware` добавьте `allow_private_network=True` —
   этот заголовок требует Chrome, когда HTTPS-сайт стучится на loopback.
   Без него запрос упадёт с ошибкой Private Network Access.
3. На сайте: кнопка **ИИ** справа внизу → ⚙ → адрес `http://127.0.0.1:8080`,
   API-ключ из панели прокси (`/webui/` → Настройки) → «Сохранить».
   Ключ лежит только в localStorage вашего браузера, в код и в git не попадает.

### Что умеет

- **Чат** — контекстом служит текущая книга, глава и живое выделение,
  ответ идёт потоком, у модели `deepseek-reasoner` отдельно показываются
  «Рассуждения».
- **Испр. / Улучш.** — две кнопки в панели выделения (рядом с Ж/К/Э+):
  первая чинит орфографию и пунктуацию, не переписывая текст;
  вторая улучшает стиль, сохраняя смысл. Результат открывается в модалке —
  «Применить» подменяет фрагмент прямо в редакторе, «Копировать» — для
  режима только для чтения.
- Настройки (адрес, ключ, модель) и статус связи с прокси — в шапке панели.

Файлы модуля: `src/js/22-assistant.js`, `src/css/12-assistant.css`,
разметка в `src/index.html` (кнопка, панель, модалка, кнопки в `#selbar`).
`dist/` держим в зеркале с `src/`.
