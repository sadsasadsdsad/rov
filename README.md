# rov
rov.smartliba.ru

## ИИ-ассистент (js/22-assistant.js)

Чат по книге и правка выделенного текста. По умолчанию запросы идут через
сам сайт: браузер → `/api/ai.php` (PHP-релей) → прокси deepseek-web2api на
том же VPS (`127.0.0.1:8080`) → DeepSeek. Ключей у читателя нет — работает
с любого устройства, браузер не знает про прокси вообще.

### Установка на сервере (однократно)

1. `git pull && sudo bash setup-server.sh` — создаёт `/var/www/rov/.aikey`
   (ключ релея, в git не попадает) и `location = /api/ai.php` в nginx
   (rate-limit 20 р/мин, `fastcgi_read_timeout 300s`, без буферизации —
   нужен для SSE-стрима).
   Если nginx-конфиг сайта живой/ручной — разово:
   `sudo bash nginx-ai-patch.sh` (бэкап в /root/nginx-backup, `nginx -t`,
   перезагрузка; повторный запуск — no-op). Тот же скрипт выставляет
   `Cache-Control`: html — `no-cache` (иначе браузер кэширует index.html
   эвристически и после обновления показывает старую вёрстку — например,
   пилюлю ИИ из прошлой версии), статика — на сутки (`?v=` в index.html).
2. Ключ должен быть читаем PHP: `chown root:www-data /var/www/rov/.aikey &&
   chmod 640 /var/www/rov/.aikey` (оба скрипта ставят права сами).
3. Код прокси и его установка:
   ```
   scp web2api.tar.gz root@сервер:/root/
   ssh root@сервер 'cd /var/www/rov && sudo bash setup-ai.sh'
   ```
   Скрипт кладёт прокси в `/opt/web2api` (код + `.env` + `data/accounts.json`),
   собирает venv, пишет юнит `web2api.service` (слушает только 127.0.0.1,
   наружу не светит) и подставляет `.aikey` в `API_KEYS` прокси.
4. Проверка: `curl https://rov.smartliba.ru/api/ai.php?action=models` → 200.

### Обновление токена DeepSeek (примерно раз в сутки)

Токен аккаунта в `/opt/web2api/data/accounts.json` живёт ~24 часа. После
истечения пинг (`/api/ai.php?action=models`) продолжает отвечать 200 и
точка связи в шапке остаётся зелёной, а **чат** падает: прокси логирует
`40003 Authorization Failed (invalid token)` и релей отвечает 500/503.
Порядок обновления:

1. В браузере войдите на `chat.deepseek.com`, на странице чата
   F12 → Console → `localStorage.userToken` → скопировать строку
   (формат `{"value":"…","__version":"0"}` — адаптер принимает и голый токен).
2. На сервере заменить поле `token` у аккаунта в
   `/opt/web2api/data/accounts.json` (сначала сделать бэкап файла).
3. `systemctl restart web2api` — рестарт обязателен: он же чинит зависший
   статус «All accounts busy» (после каждой неудачной попытки аккаунт
   застревает в busy, и повторы до рестарта отвечают 503).
4. Проверка: POST `/v1/chat/completions` на `127.0.0.1:8080` с ключом из
   `.env` → 200 с текстом ответа.

### Режим со своим прокси (разработка)

Кнопка **ИИ** — в верхней панели (на месте «Все заметки»: заметки теперь
через Энциклопедию → вкладка «Заметки») → ⚙ → адрес `http://127.0.0.1:8080` и ключ
`sk-…` из панели прокси (`/webui/`) → «Сохранить». Браузер идёт напрямую в
локальный прокси (в `.env` прокси нужен `ALLOWED_ORIGINS=…`, в `server.py`
в CORSMiddleware — `allow_private_network=True`), ключ хранится только в
localStorage. Пустой адрес = режим по умолчанию, через сайт.

### Что умеет

- **Чат** — контекстом служит текущая книга, глава и живое выделение,
  ответ идёт потоком, у модели `deepseek-reasoner` отдельно показываются
  «Рассуждения».
- **Полностраничный чат (#aiPage, стиль DeepSeek)** — кнопка ⤢ в шапке
  панели открывает страницу на весь экран: слева список диалогов
  («＋ Новый чат», переключение, удаление), справа та же лента с чипами
  и карточками. История живёт в localStorage (`chernovik.ai.threads.v1`:
  до 20 диалогов, последние 40 реплик с обрезкой длинных полей) и
  переживает перезагрузку; контекст книги/главы снимается в момент
  создания диалога, так что вопрос со страницы идёт с тем же контекстом.
  Панель остаётся для быстрых вопросов — обе ленты показывают один и тот
  же активный диалог (`data-aimsgs`); «Назад» со страницы возвращает
  (и переоткрывает панель, если страница открыта из неё). На узких
  экранах список диалогов — выдвижной ящик (☰ в шапке).
- **Испр. / Улучш.** — две кнопки в панели выделения (рядом с Ж/К/Э+):
  первая чинит орфографию и пунктуацию, не переписывая текст;
  вторая улучшает стиль, сохраняя смысл (запрет канцелярита и штампов,
  объём ±10%). В модель уходит фрагмент с абзацами, «Применить»
  применяет ответ по месту: абзацы и заголовки сопоставляются с блоками
  выделения, теги `<h1>/<b>/<i>` и не тронутая часть соседнего абзаца
  остаются на месте (запасной путь — простая подмена, как раньше).
  Результат открывается в модалке — «Применить» подменяет фрагмент
  прямо в редакторе, «Копировать» — для режима только для чтения.
- **Создание книг и глав** — попросите словами (или чипом «＋ Новая книга»
  в панели): модель отвечает JSON-действием (`create_book` /
  `create_chapter` / `replace_chapter`), в ленте появляется карточка
  с планом (список глав, объём), книга/глава создаётся по кнопке —
  `<h1>` + `<p>`, служебные главы как в обычной книге, `persist()`.
  Служебные главы («Памятка», «Заметки») заменять нельзя.
  Если модель ответила текстом («Нажмите "Создать книгу"»), а JSON не
  прислала — `aiTryAction` сам уточняет один раз прямо в диалоге
  (`aiFixAction`) и дорисовывает карточку; в историю API упакованный
  JSON (`aiActionMsg`), чтобы она не повторяла саммити вместо действия.
  Если уточнение тоже не помогло — вместо вводящего в заблуждение
  «нажмите кнопку» пишется честное «Модель не прислала данные для
  создания…» (`aiActionFailed`).
  Заголовок главы-строкой и алиасы полей валидация тоже переваривает.
  Состояние карточки («создана») сохраняется вместе с диалогом.
- **Типографика ленты** — ответы проходят `aiChatFmt`: русские кавычки
  «…», тире — и диапазоны 5–10, троеточие …, маркеры списков → «—»,
  markdown-шум и пробелы перед знаками убираются. «Рассуждение»
  сворачивается в `<details>` (раскрытым остаётся, пока стриминг
  пересобирает ленту, — `aiThinkOpen`), карточка действия с искрой и акцентной
  кнопкой «Создать книгу» (видна сразу), серии реплик одного
  собеседника группируются плотнее (`.tight`).
- **Промпты правки и книг** — «Улучшить» работает только над тем, КАК текст
  написан (ясность фраз, ритм, повторы, канцелярит, штампы), с запретом
  менять сюжет/факты/цифры и с откатом «без изменений», если улучшать
  нечего; «Исправить» — только орфография/пунктуация, включая слитные
  написания. Книги пишутся связной сюжетной дугой (3–7 абзацев живой
  прозы на главу, без морали и пересказа «как будто»).
- **Панель выделения** — менюшка и синонимы выезжают через ~0.85 с
  спокойного выделения, а не мгновенно (`transition-delay` в
  `04-editor.css` + `THESAURUS_DELAY`).
- **Кнопка ИИ** — обычная иконка-искра в верхней панели редактора (на месте
  «Все заметки»: заметки открыть через Энциклопедию → вкладка «Заметки»)
  и в шапке библиотеки — без подложки и точки связи, как соседние иконки.
  Статус связи — крохотная точка `data-aidot` в шапках панели и страницы
  (без надписи). Иконка ИИ —
  единая минималистическая искра `AI_SPARK` (кнопки, шапки, пустое
  состояние, карточка действия). Во время генерации кнопка отправки
  превращается в «Стоп» (квадрат `AI_STOP_SVG`) — на странице и в панели
  одновременно. Строка ввода растёт по тексту, полоса прокрутки появляется
  только при реальном переполнении (`aiAutosize`).
- **Сбои** — если DeepSeek недоступен (5xx/429/обрыв сети), в ленте
  «DeepSeek временно недоступен — повторим через минуту» и кнопка
  «ПОВТОРИТЬ» (автоповтор один раз), в модалке правки — своя кнопка
  «ПОВТОРИТЬ». Точка связи в шапках тоже сама перепроверяется.
- Настройки (адрес, ключ, модель) — общая модалка `#aiSetModal`
  (⚙ в шапке панели и на странице); пустой адрес = через
  сайт.

Файлы модуля: `src/js/22-assistant.js`, `src/css/12-assistant.css`,
разметка в `src/index.html`, релей `src/api/ai.php`, серверные скрипты
`setup-ai.sh` и `nginx-ai-patch.sh`. `dist/` держим в зеркале с `src/`.
